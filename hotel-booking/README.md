# Hotel Booking Database

A practical reservation system for guests, rooms, bookings, payments, and room availability. It helps students practice date-range overlap, status filtering, occupancy reports, and booking constraints.

## Run

```bash
psql -d learning_lab -f 01_schema.sql
psql -d learning_lab -f 02_queries.sql
```

Use fictional guests and test dates. Extend the project with seasonal pricing, housekeeping tasks, or cancellation policies.
