# Personal Banking Database

A fictional personal-finance project for accounts, categories, transfers, transactions, and monthly spending. It helps students practice ledgers, balances, date grouping, transfer relationships, and safe financial reporting.

## Run

```bash
psql -d learning_lab -f 01_schema.sql
psql -d learning_lab -f 02_queries.sql
```

This is an educational model using fictional data. Add recurring payments, budgets, or account reconciliation as extensions.
