# Restaurant Reservations Database

An original reservation-system project inspired by real-world booking applications. Practice guests, tables, reservations, party sizes, and availability reports.

## Learning goals

- Model reservations against physical tables
- Validate party sizes and reservation states
- Find daily capacity and upcoming bookings
- Detect overlapping reservations for the same table

## Run

```bash
psql -d learning_lab -f 01_schema.sql
psql -d learning_lab -f 02_queries.sql
```
