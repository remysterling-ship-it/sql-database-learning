# E-commerce Orders Database

A practical order-management project for customers, products, orders, payments, and shipping status. It helps students practice order grain, line-item modeling, revenue reports, constraints, and customer analytics.

## Run

```bash
psql -d learning_lab -f 01_schema.sql
psql -d learning_lab -f 02_queries.sql
```

Use fictional data only. Extend it with discounts, refunds, product reviews, or monthly sales dashboards.
